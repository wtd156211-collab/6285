# 位图旋转与缩放（从 0 实现）

起始环境只有这份说明、`samples/**` 与 `.gitignore`，没有代码可抄。要新写 `affinepix` 包（Python 3.13、标准库）、
命令行 `python -m affinepix`、用样例跑出来的对比页面与 `tests/`（`unittest`）。

## 一、范围

要做：读未压缩位图，按清单逐条做「先缩放到目标尺寸、再绕中心旋转」的变换；按第三节采样；结果写回同格式位图；
给出每条变换的输出尺寸与像素校验值；再用引擎的输出生成并排对比页面。

不做：图片解码（只吃第二节格式）；裁剪、镜像、透视与更一般的仿射矩阵；通道混合、滤镜、抖动、透明、色彩管理；
双三次/兰索斯与多重采样抗锯齿（每像素只按第三节取 1 或 4 个输入像素）；批量目录、增量缓存、并发；联网、第三方依赖、构建步骤。

## 二、位图格式

输入输出都是 24 位未压缩 BMP（`BITMAPINFOHEADER`、`BI_RGB`）：14 字节文件头 + 40 字节信息头 + 像素。

- 像素偏移按 `bfOffBits` 读（样例写 54，别写死）；`biSize=40`、`biPlanes=1`、`biBitCount=24`、`biCompression=0`。
- 每像素 3 字节，顺序 `B,G,R`；每行按 4 字节对齐，`stride = (宽 × 3 + 3) // 4 × 4`，行尾填充不算像素。
- 行序自下而上，文件第一行是最下面一行；输出同格式（`bfOffBits=54`、`biSizeImage` 按实际写、分辨率与调色板字段 0）。
- 头不合法（缺失、`biSize`≠40、位深≠24、压缩≠0、宽高≤0）按第四节退出码 1 处理。

## 三、口径与公式

`deg` 是整数度（样例取 −180..180），`θ = deg × π / 180`，全程双精度浮点。x 向右、y 向下，像素 `(x, y)` 覆盖
`[x, x+1)×[y, y+1)`、中心 `(x+0.5, y+0.5)`。`size=-` 表示不缩放（`tw = W`、`th = H`），否则给目标尺寸。

画布：

```
Wo = ceil9(|tw·cosθ| + |th·sinθ|)        Ho = ceil9(|tw·sinθ| + |th·cosθ|)
```

`ceil9(v) = ceil(round(v, 9))`：先四舍五入到 9 位小数再向上取整，90°、180° 这类角度不会因浮点误差多出像素。

反查（逐像素算）：① 输出像素 `(X, Y)` 的中心相对画布中心 `(Wo/2, Ho/2)` 得 `u = X + 0.5 − Wo/2`、
`v = Y + 0.5 − Ho/2`；② 反旋转回目标尺度 `dx = u·cosθ − v·sinθ`、`dy = u·sinθ + v·cosθ`；③ 到目标尺度图上
`px = tw/2 + dx`、`py = th/2 + dy`；④ 换回源图坐标（先乘后除）`fx = (px × W) / tw`、`fy = (py × H) / th`。
缩放与旋转只重采样一次，不许拆成两次。`deg > 0` 是逆时针（源图中心右边一点转到输出中心正上方）。

采样方式只看清单里的 `sample=`，实现不许自己挑：

- `nearest`：`ix = floor(fx)`、`iy = floor(fy)`，取该像素。
- `bilinear`：`x0 = floor(fx − 0.5)`、`y0 = floor(fy − 0.5)`、`ax = fx − 0.5 − x0`、`ay = fy − 0.5 − y0`；取
  `(x0,y0)`、`(x0+1,y0)`、`(x0,y0+1)`、`(x0+1,y0+1)` 四点，权重 `(1−ax)(1−ay)`、`ax(1−ay)`、`(1−ax)ay`、`ax·ay`；
  三通道各算加权和，最后 `min(255, max(0, floor(v + 0.5)))`（`.5` 向上）。
- 越界填充：采样位置 `(i, j)` 不在 `0 ≤ i < W`、`0 ≤ j < H` 内时一律取 `(0,0,0)`，不复制边缘、不钳位；
  双线性四点各自判定，图外的点按黑色参与加权。

## 四、输入输出与文件格式

命令都在仓库根目录跑；文本都是 UTF-8、LF、末行有换行。

### 4.1 变换清单 `samples/ops/<名>.txt`

```
image=samples/images/<名>.bmp
angle=<整数度> size=<宽x高|-> sample=<nearest|bilinear>
```

第一行给位图路径；其余每行一条变换，字段序固定、单空格分隔；`#` 与空行忽略，编号从 1 起。样例里尺寸是 1..4096。

### 4.2 命令行

```
python -m affinepix run  <操作清单> --out <输出目录>
python -m affinepix page <操作清单> --dir <输出目录> --html <页面文件>
```

`run` 逐条算完，写 `<输出目录>/<名>.<编号>.bmp`（两位编号）与 `<输出目录>/report.txt`：一条变换一行、无注释行，
字段固定：

```
<编号> angle=<角度> size=<目标尺寸|-> sample=<采样> w=<宽> h=<高> pixels=<宽×高> sum_rgb=<整数> sha256=<64 位小写十六进制>
```

像素校验值按规范序算：自上而下、行优先、每像素 `R,G,B` 三字节，不含填充与头；`pixels = 宽 × 高`，`sum_rgb` 是这串
字节的字节和，`sha256` 是这串字节的 sha256。退出码 `0` 成功、`1` 输入不可用（位图/清单缺失或不合法、目录不可写）、
`2` 用法错误；非 0 不写半成品。

### 4.3 对比页面

`page` 读清单与 `run` 的输出，写一个自包含 HTML：UTF-8 单文件、双击即开、不引外部资源、不联网、不构建。每条变换一节：
写编号、角度、目标尺寸与采样方式；原图与结果并排画成两块 Canvas，都标像素宽高；下面再放一块像素放大视图（倍数自定）。
像素只能来自两张位图，尺寸只能来自位图的头；页面不许自己重算几何变换，也不许写时间戳与绝对路径。
`<dir>` 里缺结果位图按退出码 1 处理。

## 五、性能与验收口径

单进程单线程、只用标准库；测试机是 Windows + Python 3.13，冷启动计入。`big.bmp`（1920×1080，2,073,600 像素）那份
清单里最大一条输出 2048×1152（2,359,296 像素）：单条 ≤ 6 s、整份 ≤ 10 s；整次 `run` 峰值常驻内存 ≤ 384 MiB
（进程外测）。其余样例都在 1 s 量级。

逐条核对：

1. `samples/expected/<名>.txt` 与 `samples/ops/<名>.txt`、`samples/images/<名>.bmp` 同名成套；`report.txt` 与 expected
   数据行逐行逐字节相同，从输出位图按 4.2 重算 `w`、`h`、`pixels`、`sum_rgb`、`sha256` 也相同。
2. 尺寸与像素只由第三节公式决定；`texture` 第 1、2 条（同几何的最近邻与双线性）校验值必须不同；`narrow` 第 1、2 条是
   精确复制与精确翻转（`sum_rgb` 相同、`sha256` 不同），`flat` 第 4 条是精确翻转。
3. `flat` 旋转后四角纯黑 `(0,0,0)`；边缘像素是图内像素与黑色的加权，不是边缘复制或钳位。
4. 同一清单连跑两次：`report.txt`、每张输出位图、页面逐字节相同；不写时间戳、绝对路径、主机名，不依赖随机数与集合
   遍历顺序。
5. 页面四项齐全（并排两图、尺寸与采样标注、像素放大视图、数值与 `report.txt` 同源），用 `texture`、`edge` 各验收一份。
6. 只用标准库，无构建无网络；`python -m unittest discover` 能跑通，测试只读 `samples/`。

## 六、样例说明

括号里是清单条数；核对方式见第五节。

| --- | --- | --- | --- |
| `texture.bmp` | 256×192 | 细纹理（棋盘、细斜线、颗粒） | 30° 最近邻与双线性各一条、缩到 64×48、17° 叠加缩到 200×150、90°（5） |
